# eBPF fleet 0.2.1

Trust and clean-build patch release.

- The release workflow now builds from green `main` and uses keyless GitHub
  OIDC cosign with provenance attestation and an SBOM.
- Clean CI sensor builds work with autopoint, explicit libbpf includes, and
  older libbpf headers.
- The rejected-ack rollout test polls the durable audit row.
- The local CLI and bundle format are unchanged from 0.2.0.

Verify the published asset with:

```bash
curl -fsSL https://raw.githubusercontent.com/meillaya/eBPF-runtime/main/scripts/install.sh | sudo sh
ebpf-fleet --version
```
